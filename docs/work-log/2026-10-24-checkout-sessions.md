# 2026-10-24 — 구독 결제 준비 세션

## 범위와 경계

승인된 현재 가격·약관을 확인한 팬의 비공개 `pending_intent` 준비 세션만 다룬다. 실제 카드 등록, 카카오페이 승인, 빌링키/SID 저장, 첫 결제, 구독 활성화는 이번 기능에 포함하지 않으며 후속 MVP 작업으로 남긴다. 준비 성공을 결제 성공으로 표시하지 않는다. 운영 약관·가격·실제 인증 정보는 시드하지 않는다.

## 스키마 체크포인트

- 현재 팬/프로필 동의/온보딩/활성 가수를 DB에서 다시 확인한다.
- 승인·게시된 불변 약관과 정확한 가격 버전을 잠그고 세션에 스냅샷한다.
- 사용자별 잠금, 요청 멱등키, 비공개 nonce 해시, 만료 및 일회 취소를 검증한다.
- 서비스 역할만 세션 RPC를 실행하며 직접 테이블 쓰기/공개 결제 키가 없다.

## 검증과 제한

보조 PGlite PG18 환경에서 2,127 pgTAP 검사(기존 2,051 + 신규 76)가 두 번 통과했다. 이는 실제 Supabase PG17 또는 다중 세션 검증이 아니다. 로컬 Docker 실행 파일이 없어 Supabase, 공식 타입 생성, 브라우저 검증은 격리 CI에서 수행해야 한다. 공식 CI 생성 타입을 가져오기 위한 스키마 체크포인트이며 아직 기능 완료 상태가 아니다.

## 애플리케이션 구현

- 팬 전용 가격·약관 화면, 두 결제 제공자 설정 상태, 명시적 준비 요청/취소 및 미구현 등록·결제 버튼을 추가했다.
- 현재 승인 정책 없이는 입력 폼·가격을 대체하지 않는다. 실제 요청 결과의 첫/정기 가격·첫 할인 자격을 표시하며 준비 동의를 향후 청구 승인으로 간주하지 않는다.
- 인증된 주체와 현재 프로필을 확인한 뒤 서비스 RPC로 비공개 세션을 만든다. CSRF Origin/JSON 크기/엄격한 입력, 무작위 nonce·해시·HttpOnly 쿠키, 같은 요청 재사용/다른 사용자/재전송/만료 경계를 검증한다.
- 콜백 GET은 토큰을 해석·저장하지 않고 모든 쿼리를 제거한 고정 경로로 이동한다. 콜백 검증/등록 완료 기능은 아직 없으며 취소 nonce 검증을 그 기능으로 주장하지 않는다.
- 공식 문서의 Toss CARD SDK 설명자와 직접 KakaoPay 0원 ready 프로토콜을 구현했다. UI/라우트에서 호출하지 않고, 승인·빌링키 교환·첫 청구 API는 제공하지 않는다. 74개 모의 HTTP 계약 테스트가 오류 분류/알 수 없는 결과/자동 재시도 금지/정확한 리다이렉트 출처를 검증한다.
- 독립 검토에서 앱 제공자 이름과 SQL enum 매핑 불일치, E2E 쿠키 wire 인코딩을 발견해 수정했다. 보안 검토자는 별도 270개 단위 테스트와 정적 검사를 통과시키고 준비 범위에 승인했다.

## 현재 검증 상태

- 전체 단위 테스트 1,240개 통과. ESLint/Prettier, 대비 검사, diff 공백 검사 통과.
- 체크포인트 CI `40096971357`의 검증된 공식 타입 아티팩트 `12561173962`를 바이트 그대로 반영했다(SHA-256 `8d0aa05abaf94d9f35c8983f4356fb8f9bc0a9b6ce747f3a9981a548d32451e7`). 로컬 `npm run check:all` 전체가 통과했다: lint, 타입 검사, 단위 1,240개, 대비 검사, Next/PWA 빌드. PWA precache는 공개 자산 27개다.
- 실제 체크포인트 CI에서 Supabase PG17 pgTAP 2,127개 ×2, 기존 경합 114개, 기존 기본 브라우저 21개/인증 브라우저 65개가 통과했다. 생성 타입 드리프트만 예상대로 실패했고 해당 산출물을 반영했다. 추가한 11개 실제 다중 세션 경합 검사 및 최종 앱 커밋의 전체 CI는 아직 필요하다. 로컬 경합 실행은 Docker ENOENT로 픽스처/SQL 실행 전에 차단되었으며 통과로 보고하지 않는다.
- 브라우저 회귀는 기존 21/65개에 기본 2개·인증 13개를 추가했고, 새 화면은 3개 글자 크기에서 19개 스크린샷을 생성하도록 준비했다. 실행/시각 검토는 격리 CI에 남아 있다. 기존 로컬 브라우저 제한을 재시도하지 않았다.
- 실제 결제 제공자 호출, 계정/카드 등록, 로그인, 키 발급, 계약·운영 약관 승인, 실제 개인정보 입력 또는 운영 배포를 수행하지 않았다.
