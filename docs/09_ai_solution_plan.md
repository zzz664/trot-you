### 2.1 에네이 vs Runyour AI — 트롯유 기준 결론

| 비교 | 에네이 GPU Starter | Runyour AI |
| --- | --- | --- |
| 돈 | 100만원 한 번에 | 30만원(+12월 30만원) |
| GPU | MI250 1장 전용, 한 달 24시간 | NVIDIA 시간제. A5000×2 기준 238시간 |
| 소프트웨어 | AMD ROCm. PyTorch는 되지만 Whisper 가속(faster-whisper/CTranslate2), 일부 TTS 라이브러리는 호환 확인 필요 | CUDA. 오픈소스 그대로 |
| 남는 예산 | 0원 | 70만원(약관 AI, STT, 디자인) |
| "서버 운영" 체감 | 한 달간 "내 GPU 서버"가 있는 경험 | 실험 끝나면 반납. 상시 서버 아님 |
| 보고서 | 한 달 뒤 "뭘 만들었나"가 명확해야 함 | 시간별 사용 로그가 자동으로 남음 |

**결론: Runyour AI를 11월에 신청하고, 쓸모가 확인되면 12월에 한 번 더 신청한다.** 트롯유 §3의 실험(자막 STT, 음성 합성 PoC)은 A5000×2나 V100×3으로 100~150시간이면 충분하다. 에네이는 "MI250 한 달 체험"으로는 매력 있지만, 트롯유 일정(11/30 출시)에 GPU 상시 서버가 필요한 작업이 없고 나머지 70만원을 포기해야 해서 맞지 않는다.

에네이를 고르는 조건이 딱 하나 있다: **12월에 자체 모델(자막 또는 음성 합성)을 실제 구독자에게 서빙하는 실증을 하기로 결정**했을 때. 그때는 12월 한 달 에네이 100만원(11월은 다른 솔루션 0원)이라는 선택지가 된다. 지금 11월에 고르는 건 아니다.

## 4. GPU 활용 방안 (Runyour AI 기준으로 다시 계산)

### 4.1 예산 → 시간

| GPU | 시간당 | 30만원으로 | 어디에 |
| --- | --- | --- | --- |
| A10 × 2 (24GB×2) | 690원 | ≈434h | Whisper large-v3 추론·평가, 소형 TTS 미세조정 |
| RTX A5000 × 2 (24GB×2) | 1,261원 | ≈238h | 위 + 중형 모델 미세조정 |
| H100 × 2 | 5,500원 | ≈54h | 꼭 필요할 때만(대형 TTS 학습) |

실험 A(자막)는 A10×2로 50~80시간, 실험 B(음성 합성 PoC)는 A5000×2로 60~100시간이면 끝난다. 30만원 안에 둘 다 들어간다.

### 4.2 과제

| 과제 | 왜 트롯유에 중요한가 | 방법 | 시기 |
| --- | --- | --- | --- |
| **A. 가수 음성 메시지 자막** | 중장년은 소리 못 듣는 상황이 많다. 글이 생기면 금칙어 검사도 글로 된다 | Whisper 계열 한국어 모델을 가수 음성 50~100개로 평가·미세조정. CER 10% 아래면 2차 기능 | 11월 실험 → 12월 적용 |
| **B. 가수 목소리로 이름 불러주기 PoC** | 음성 메시지에서 "순자 님"을 가수 목소리로 끼우면 **다른 서비스가 못 하는 차별점** | 오픈소스 한국어 TTS/음성 변환 모델 미세조정. **가수 서면 동의 전엔 팀원 목소리·공개 데이터로만** | 11월 PoC, 적용은 계약 후 |
| C. 금칙 분류기 | 정규식 우회 방지 | 작은 분류 모델. API가 더 쌀 수 있음 | 낮음 |

### 4.3 Runyour AI 주의사항 (공급사 안내 그대로)

- 프로그램을 꺼도 **반납 전까지 과금**된다. 세션 끝나면 콘솔에서 반납.
- 반납·크레딧 소진 시 **데이터 초기화**. 모델·결과는 네트워크 저장소 또는 외부(HF Hub, S3)에 백업. 저장소는 별도 차감.
- Docker 불가. vLLM·Ollama는 직접 설치.
- 원하는 GPU가 대여 중이면 못 쓴다. A10/A5000/V100 중 되는 걸로.
- 크레딧 1년 유효. 11월에 다 못 써도 된다.
