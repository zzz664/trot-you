# trot-you

프로젝트 초기화 단계입니다. 애플리케이션 구현 및 테스트는 아직 시작하지 않았습니다.

## 브랜치 운영

- `main`: 배포용 브랜치.
- `develop`: 개발 통합 및 기본 브랜치로 사용할 브랜치.
- `develop`에 직접 푸시하지 않습니다.
- 기능 하나마다 별도 브랜치 하나를 만들고 PR로 `develop`에 병합합니다.
- 기능 완료 및 검증 후 PR을 병합하고 해당 기능 브랜치를 삭제한 다음 다음 기능을 진행합니다.
- 배포는 개발 기능 완료와 구분하여 수행합니다.

## 작업 기록

구현 변경 시 작업 목적, 변경 내용, 설계 결정, 실행한 테스트와 결과, 미검증 항목을 저장소의 작업 기록 파일에 남깁니다. 비밀키, 비밀번호 및 민감한 정보는 커밋하지 않습니다.
